# Behance 포트폴리오 검색 결과 페이지 디자인 시스템

## 프로젝트 정보
- **출처 페이지**: Behance "포트폴리오" 검색 결과 (`https://www.behance.net/search/projects/포트폴리오`)
- **분석 날짜**: 2026-07-08
- **적용 프로젝트**: lecture1 디자인 레퍼런스
- **분석 방식**: Playwright MCP로 접속 후 accessibility snapshot(DOM 구조) + 전체 페이지 스크린샷을 함께 확인하여 스크롤 전 구간의 레이아웃/컴포넌트 구조를 분석. 컬러 값은 분석 범위에서 제외.
- **스크린샷**: `lecture1/behance-portfolio-search-full.png` (전체 페이지), `lecture1/behance-portfolio-search.png` (첫 화면)
- **분석 범위**: 데스크톱 뷰포트 기준. 모바일/태블릿 레이아웃은 실측하지 않아 이 문서에 포함하지 않음.

## 1. 전체 페이지 구조 (Top → Bottom)

```
1) 상단 고정 헤더 (로고 + 데스크탑 내비게이션 + 로그인 버튼)
2) 검색·필터 바 (필터 버튼 + 검색창 + 탭 내비 + 정렬 버튼)
3) 카테고리 캐러셀 (가로 스크롤 아이콘 칩)
4) 결과 카운트 + 필터 태그 목록
5) 프로젝트 카드 그리드 (feed)
6) 로그인/가입 유도 섹션 (그리드 하단, 화면 정중앙)
7) Pro 업그레이드 배너
8) 4열 구조 Footer + 로고
```
페이지는 위에서 아래로 "탐색(헤더/검색) → 필터링(태그) → 콘텐츠(그리드) → 전환 유도(로그인) → 사이트맵(푸터)" 순서로 정보 위계가 구성되어 있다.

## 2. 헤더 & 내비게이션

### 구성 요소
- 좌측: 로고(단일 워드마크, 클릭 시 홈 이동)
- 데스크탑 전용 리스트 내비게이션: 로그인 상태에 따라 표시가 달라지는 구조(비로그인 시 "로그인" 버튼만 노출)
- 모바일 대응을 위한 별도의 "모바일 기본 탐색 메뉴" 버튼이 DOM에 항상 존재(현재 데스크톱 뷰에서는 숨김 처리로 추정)

### 설계 포인트
- 헤더는 검색 바와 분리된 별도 레이어로, 검색 바가 실질적인 "2차 헤더" 역할을 하며 페이지 상단에 두 겹으로 쌓이는 구조다.
- 접근성을 위해 "메인 콘텐츠로 건너뛰기" / "바닥글로 건너뛰기" 스킵 링크가 시각적으로 숨겨진 채 DOM 최상단에 배치되어 있다.

## 3. 검색 & 필터 바

### 구성 요소 (좌 → 우 순서)
1. **필터 버튼**: 아이콘 + "필터" 라벨. 클릭 시 좌측 패널/드롭다운으로 상세 필터(카테고리, 라이선스 등)를 전환하는 토글형 버튼.
2. **검색 인풋**: 아이콘 + 콤보박스(자동완성 지원 텍스트 입력). 현재 입력값이 텍스트로 유지되며 우측에 입력 초기화(X) 버튼이 붙는다.
3. **탭 내비게이션**: "프로젝트 / 인물 / 기타" 세그먼트 컨트롤 형태로, 동일한 검색어를 다른 검색 대상으로 전환한다.
4. **정렬 버튼**: "정렬 - Recommended" 형태의 드롭다운 트리거. 아이콘 두 개(정렬 아이콘 + 화살표)로 구성.

### 설계 포인트
- 필터·검색창·탭·정렬이 하나의 수평 바에 압축되어 있어, 검색 관련 조작을 한 시선 높이에서 모두 처리하도록 설계됨.
- 탭 내비게이션이 검색창 바로 아래가 아니라 옆에 나란히 배치되어, 결과 페이지 전환 시 스크롤 없이 즉시 접근 가능하다.

## 4. 카테고리 캐러셀 (추천 칩 리스트)

### 구성 요소
- 가로 스크롤 가능한 `list` 구조. 각 아이템은 "아이콘 + 텍스트 라벨" 조합의 캡슐형 칩(pill)이다.
- 확인된 항목: `For You`, `Following`, `최고의 Behance`, `그래픽 디자인`, `design`, `그래픽디자인`, `디자인`, `graphic design`, `graphic designer`, `branding` 등. 검색어와 연관된 태그가 동적으로 첫 줄을 채우고, 그 뒤에 고정 카테고리가 이어지는 하이브리드 구조로 추정됨.
- 우측 끝에 다음 항목을 더 보여주는 화살표(`>`) 컨트롤이 있어, 칩 목록이 유한한 가로 슬라이더임을 나타낸다.

### 설계 포인트
- 칩 형태(알약형, 둥근 모서리)는 검색 결과 카드(사각형)와 형태적으로 대비되어, "필터/탐색 레이어"와 "콘텐츠 레이어"를 형태만으로 구분시킨다.
- 첫 칩(`For You`)과 두 번째 칩(`Following`)이 강조 색으로 고정되어 있어, 개인화 진입점이 항상 캐러셀의 맨 앞에 오도록 우선순위가 설계되어 있다.

## 5. 프로젝트 카드 컴포넌트 (핵심 콘텐츠 단위)

각 카드는 접근성 트리 상 `article`로 래핑되며, 내부 구조는 다음과 같이 3개 레이어로 나뉜다.

### 5.1 썸네일 레이어
- 프로젝트 대표 이미지(가변 비율 — 정사각형에 가까운 카드부터 세로로 긴 카드까지 혼재해, 매스너리(masonry)에 가까운 그리드 느낌을 줌).
- **카테고리 배지**: 썸네일 좌측 상단에 오버레이되는 아이콘형 라벨(예: "최고의 Behance", "브랜딩"). 클릭 시 해당 카테고리 갤러리로 이동하는 링크.
- **저장(무드보드 추가) 버튼**: 썸네일 우측 상단에 오버레이되는 아이콘 + "저장" 텍스트 버튼. 마우스 오버 시에만 노출되는 상호작용 요소로 추정됨.
- 썸네일 전체가 프로젝트 상세 페이지로 연결되는 링크 역할을 겸함.

### 5.2 메타 정보 레이어 (썸네일 하단)
- **제목**: 링크 텍스트, 카드 내에서 가장 큰 글자 크기의 텍스트 요소.
- **통계 행**: "평가(좋아요) 아이콘 + 숫자", "조회수 아이콘 + 숫자"가 나란히 배치. 숫자는 1천 단위부터 "4.8천"처럼 축약 표기됨(정확한 값은 스크린리더 텍스트로 별도 제공: 예 "조회수 4,758회").
- **작성자 행**: 작성자명 링크 + (해당 시) "Pro" 멤버십 배지 버튼.

### 설계 포인트
- 카드 하나에 "무엇인지(제목) → 얼마나 반응이 좋은지(통계) → 누가 만들었는지(작성자)" 순으로 정보가 위→아래로 흐르도록 배치되어, 스캔 시 시선 이동이 짧다.
- 카테고리 배지와 저장 버튼을 텍스트 레이어가 아닌 이미지 위 오버레이로 배치해, 메타 정보 레이어의 타이포그래피를 방해하지 않으면서도 핵심 액션(저장, 카테고리 이동)을 이미지 자체에서 즉시 실행할 수 있게 함.
- Pro 배지는 작성자명 옆에만 붙어, "콘텐츠 신뢰도"가 아닌 "작성자 등급" 정보로만 한정해 사용됨.

## 6. 그리드 시스템

- 스크린샷 기준 데스크톱에서 **3열 그리드**로 카드가 배열되며, 한 화면 스크롤 분량에서 24개 카드가 8행 × 3열로 노출됨.
- 카드 간 간격은 균일한 gutter로 유지되어 격자가 흐트러지지 않으며, 각 열의 카드 높이는 썸네일 비율에 따라 달라져 전체적으로는 핀터레스트류의 매스너리 그리드에 가까운 인상을 준다(단, 열 자체는 고정된 3열 구조).
- 그리드 상단에 "결과 수(예: 6,000+ 결과)" 텍스트와 "필터 태그" 영역이 별도 리전으로 분리되어, 그리드 진입 전 현재 검색 컨텍스트를 먼저 안내한다.

## 7. 로그인/가입 유도 섹션 (Auth Gate)

- 카드 그리드 바로 아래, 화면 폭 기준 중앙 정렬된 좁은 컬럼에 배치.
- 구성 순서: 안내 문구 → 소셜 로그인 버튼 스택(세로로 쌓인 전체 너비 버튼 3개: Google / Kakao / Apple) → "더보기" 텍스트 링크(추가 로그인 수단 확장) → 구분선("또는") → 이메일 입력 폼 + "계속" 버튼.
- 버튼이 모두 동일한 너비·높이의 세로 스택으로 통일되어 있어, 다수의 로그인 옵션을 제공하면서도 시각적 위계는 "모두 동등한 선택지"로 처리함.
- 이 섹션이 그리드와 푸터 사이, 페이지의 정중앙 폭에 배치되어 무한 스크롤형 콘텐츠 소비를 이 지점에서 의도적으로 차단하는 게이트 역할을 한다.

## 8. Footer

- **4단 컬럼 구조**: "크리에이티브를 위한 서비스 / 인재 찾기 / Behance / 소셜".
- 각 컬럼은 헤딩(카테고리명) + 텍스트 링크 리스트로 구성되며, 소셜 컬럼만 아이콘 기반 링크(Instagram, 트위터, Pinterest, Facebook, LinkedIn)로 예외적으로 표현됨.
- 최하단에 로고 + 저작권 문구 + 언어/약관/개인정보 링크 바가 별도 행으로 분리되어, "탐색용 링크(4단 컬럼)"와 "법적/메타 정보(하단 바)"의 위계를 명확히 구분한다.

## 종합 요약

이 페이지는 (1) 검색·필터 조작을 상단 한 줄에 압축하고, (2) 카테고리 캐러셀로 빠른 재탐색 경로를 제공하며, (3) 카드 자체는 이미지 오버레이(카테고리/저장)와 하단 텍스트 메타(제목/통계/작성자)로 역할을 분리하고, (4) 무한할 것 같은 콘텐츠 그리드 중간에 로그인 게이트를 배치해 전환을 유도하고, (5) 마지막에 사이트 전체 사이트맵 성격의 푸터로 마무리하는, "탐색 → 소비 → 전환 → 사이트맵"의 전형적인 콘텐츠 플랫폼 레이아웃 패턴을 따른다.
